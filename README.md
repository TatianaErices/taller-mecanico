# Taller Mecánico

Proyecto para el modelado completo de un sistema de taller mecánico.

## Descripción

Este repositorio contiene el desarrollo e implementación del modelo completo de un **Taller Mecánico**, correspondiente al ejercicio del módulo **Programación Orientada a Objetos Segura** del **segundo semestre del año 2026**.

## Objetivos

- Diseñar y construir la arquitectura del modelo orientado a objetos para la gestión de un taller mecánico.
- Aplicar principios de POO y directrices de desarrollo seguro.
- Gestionar entidades del dominio tales como clientes, vehículos, mecánicos, órdenes de trabajo y repuestos.
